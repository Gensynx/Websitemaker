Websitemaker tools

Point a QR code at a PDF.

Paste the address of a PDF that is already online, or host one in this repo and let the tool build the address for you. Style the code, then download it as a PNG or a print-ready SVG. Everything runs in your browser: nothing is uploaded anywhere.

1 Which PDF?

It must be a public address a phone can open. A file:/// path from your own computer will not work on anyone else's device.

Put the file in qr-pdf/pdfs/ in the repo, commit, and push. Once the site redeploys, that address is live and the code below will open it.

2 Straight to the file, or via a landing page?

A landing page shows a title and a download button, which reads better on a phone than a raw PDF.

3 Style

Scanning opens

Scan it with your own phone before you print a hundred of them. Codes with a pale colour, a dark background or a tight crop are the ones that fail in the wild.

Hosting a PDF in this repo

A QR code holds an address, not a file, so the PDF has to live somewhere a phone can reach. If you do not already have a home for it, this repo works: it is published as a static site, so anything committed is served as-is.

01

Add the file

Drop the PDF into qr-pdf/pdfs/. Lower-case names without spaces travel best: spring-menu.pdf.

02

Commit and push

The site redeploys on push. Open the address in a browser to confirm the PDF is live before printing anything.

03

Generate and print

Use the tool above with that file name. Keep the file name stable and you can replace the PDF later without reprinting the code.
