# Halcyon Drive

Single page site for **Halcyon Drive** (Halcyon Drive Ltd), a fictional demo brand: a private fleet of performance cars for self drive hire in London. All names, reviews and contact details are invented for the demo; the phone number is from the Ofcom drama range (07700 900123).

## Structure
```
index.html   the complete site (fonts, images and styles embedded, no external files)
```

`index.html` is fully self contained: fonts are loaded from Google Fonts and all imagery is embedded, so the folder can be hosted anywhere with no build step.

## Deploy
- **Netlify**: drag this folder onto https://app.netlify.com/drop for an instant URL, or connect the repo.
- **GitHub Pages**: repo Settings → Pages → Source = `main` / root. This site lives at `https://gensynx.github.io/Websitemaker/car-hire/`.
- **Vercel**: import the repo, framework preset "Other", no build command.
